# Prototype, Module 1

- **What I built:** Offline clickable, scripted UX demonstration: event classification queue with source evidence, suggested category, confidence, exception routing and expert override. No live AI or deployed prototype verified.
- **Tool used:** ChatGPT-generated standalone HTML/JavaScript demo.
- **Prototype link:** [Offline demo](prototype-demo.html); approved shareable hosted URL pending.
- **AI Value Archetype:** Automator (with Copilot support for exceptions).
- **Bet in 1 sentence:** Automating routine wind turbine event classifications and comments for TAM will materially reduce processing time without compromising reliability, using existing data and approved models.
- **Kill criteria:** At week 4, stop if data access is not feasible or an approved native alternative meets requirements at lower total cost. At week 12, stop/pivot if accuracy of automatic classifications is below 95%, successful automation below 70% of all in-scope events, or manual effort reduction below 50%; any unresolved critical reliability/security issue blocks rollout.

**Initial confidence:** 70% subjective hypothesis, not a measured probability.

## Prototype scope
Use synthetic records only: event queue, evidence panel, category suggestions, confidence bands, mandatory review for critical cases, and audit/override history. No write-back or real operational data in a public demo.
